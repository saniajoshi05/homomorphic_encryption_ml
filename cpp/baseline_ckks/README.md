# Baseline CKKS Example (Microsoft SEAL)

This folder contains the original 5_ckks_basics.cpp example from the Microsoft SEAL library.  
It serves as the **starting point** for all experiments and parameter tuning.  
All later versions and modifications will be compared against this baseline to measure performance, accuracy, and computational trade-offs.

## Files
- ckks_basics_initial.cpp – unmodified CKKS example from SEAL
- README.md – description of this baseline setup
